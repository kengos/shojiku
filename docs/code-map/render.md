# Code map — engine/render-pdf, engine/render-png

> AI-only, token-dense. Index + repo-wide conventions: [CLAUDE.md](../../CLAUDE.md).
> Read this BEFORE searching or editing the covered dirs; update it in the
> same PR whenever files/modules/boundaries here change.

- `engine/render-pdf/src/` — `lib.rs` (`render_pdf` + font embedding) with `annot.rs` (per-line/run/image-box krilla link annotations, added after the surface closes; clip recursion + fail-closed degenerate-rect guards) and `draw.rs` (krilla draw calls; **`box_path`** picks the plain rect or the layout-built rounded path so a box's fill, stroke and clip follow one curve, and **`dash_of`** maps a tree `Dash` to a krilla `StrokeDash` — rejecting a non-positive/non-finite interval, which tiny-skia would answer by dropping the whole stroke; write-only PDF; fonts subset automatically; raster images via krilla `raster-images` feature — pure codecs, no ttf-parser; SVG + form-mark paths (`LayoutItem::Path`) played back via `svg_path`, marks stroked with `round_stroke`; clip groups via `push_clip_path`/`pop`, depth-capped + fail-closed), `paint.rs` (**`svg_fill`**: `SvgPaint` → krilla `Fill`, solid + linear/radial gradient paints) and `text.rs` (glyph drawing per `RunView` — plain implicit run or rich span runs — fallback-chain glyphs grouped into per-face segments via `shape_run`, per-run fill/stroke/skew/decoration; `map_glyphs`/`em_advance`/`italic_skew`; shaping happens once in the layout font layer (`shape_run`) — the renderer only draws the decided glyph ids/advances/`x_offset`/`y_offset`, never re-shaping; **`text/vertical.rs`** takes over when `block.vertical` is set — `arrange_vertical` per column (a plain column in the block style, a rich column iterating its per-span `TextRun`s each at its own down-offset `line.y + run.x` / font / size / color), upright glyphs centered + stacked down, `mixed` Latin rotated 90° cw via `rotate_cw90` (`Transform::from_row(0,1,-1,0,cx+cy,cy-cx)`); rebuilds each column's `RunOptions` (spacing + block trim + column-head flag + the block's tate-chu-yoko `text_combine`), scales a compressed combined glyph about its pen origin (`scale_about`, mirrored in the PNG backend), and draws the per-column/per-run SIDE decoration bands at the layout-resolved offset).

- `engine/render-png/src/` — `lib.rs` (`render_png` + **`render_raw`** (encode-free per-page **`RawPage`** `{ width_px, height_px, rgba }` — un-premultiplied RGBA the WASM canvas paints via `ImageData`, skipping the PNG encode; both share **`RenderRun`** = the ONE validate/cap home whose `rasterize` consumes pages ONE AT A TIME — the PNG path encodes+drops each pixmap so peak memory stays one canvas) + the single-page primitives **`render_png_page`/`render_raw_page`** (`page: usize`, 0-based, bounds-checked via `page_at` → **`RenderPngError::PageOutOfRange`**; byte-identical to that page of the all-pages fns — a host renders ONE page instead of every page), canvas caps) with `paint.rs` (tiny-skia `Painter`; **`box_path`**/**`dash_of`** mirror the PDF backend's (same rounded path, same solid fallback for an unusable pattern); `draw_path` plays back `LayoutItem::Path` (marks) via the shared `build_path` with round caps/joins; clip groups as an intersected `Mask` threaded through every draw call, depth-capped + fail-closed), `paint/text.rs` (per-`RunView` glyph-outline fills, synthetic bold/italic + decoration per run; **`draw_text_vertical`** (in the `paint/text/vertical.rs` submodule) takes the vertical-writing column path when `block.vertical` is set — a plain column in the block style, a rich column iterating its per-span `TextRun`s — sharing the `rotate_cw90` sign and the `scale_about` combined-cell compression with the PDF backend, incl. the rebuilt `RunOptions` (block trim + `text_combine`) and the side decoration bands), `paint/gradient.rs` (**`svg_paint`**: `SvgPaint` → tiny-skia `Paint`, solid + linear/radial gradient shaders) and `paint/image.rs` (raster/SVG drawing) painting the *same* layout tree to per-page PNGs (Preview stage). Glyph outlines via `FontFace::glyph_path`, raster pixels via `shojiku_image::decode_raster`, SVG replayed as paths; a uniform `scale` (px/pt) is the only transform.
